# Team Documentation

This directory is the shared operating manual for BMS Integration. Keep these
documents current so a new engineer can understand the project without relying
on private messages or access to a production Home Assistant installation.

| Document | Purpose | Update when |
| --- | --- | --- |
| [Project status](PROJECT_STATUS.md) | Current capabilities, risks, and priorities | A release, incident, decision, or priority changes |
| [Onboarding](ONBOARDING.md) | How to set up, validate, and contribute | The workflow or repository structure changes |
| [Engineering rules](ENGINEERING_RULES.md) | Architecture, availability, command, and release rules | A technical decision or quality rule changes |
| [Control Center brief](CONTROL_CENTER_BRIEF_RU.md) | Sidebar interface capabilities and backend contract | The planned panel or its API changes |

The pull request that changes a feature should also update the relevant status,
onboarding, or engineering document. Documentation is part of the delivery,
not a separate follow-up task.
